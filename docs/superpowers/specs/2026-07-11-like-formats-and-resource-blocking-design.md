# 点赞格式与固定资源拦截设计

## 目标

- 图片和视频媒体请求在每次同步时固定阻止，不再向用户提供开关。
- 点赞量支持“准确数字 / W / 万 / K / 千”五种显示格式。
- 未采集到观看进度时不显示“已看 0%”；只有明确的数值进度才显示百分比。

## 数据与兼容

- `SyncOptions` 删除 `blockMedia` 和 `blockImages`，Rust 调用采集器时固定添加 `--block-images`，且不添加 `--no-block-media`。
- 本地设置不再保存资源拦截字段；旧设置中的同名字段被忽略。
- `LikeCountFormat` 使用 `exact | w | wan | k | qian`。现有 `exact`、`wan`、`k` 设置继续有效，未知值回退到 `wan`。

## 显示规则

- `exact`：使用千位分组，例如 `12,345`。
- `w`：达到 10,000 后除以 10,000，显示 `W`。
- `wan`：达到 10,000 后除以 10,000，显示 `万`。
- `k`：达到 1,000 后除以 1,000，显示 `K`。
- `qian`：达到 1,000 后除以 1,000，显示 `千`。
- 单位格式最多保留一位小数并移除 `.0`；低于阈值时显示准确数字。
- `watchProgressRate` 为 `undefined` 时返回空值；数值 `0` 仍表示明确采集到 0%，可以显示“已看 0%”。

## 验证

- Vitest 覆盖五种点赞量格式、阈值、缺失进度和明确零进度。
- Rust 测试断言同步调用始终阻止图片和媒体，且 `SyncOptions` 不再暴露相关字段。
- 通过 TypeScript 类型检查、完整测试、前端构建和 NSIS 构建。
