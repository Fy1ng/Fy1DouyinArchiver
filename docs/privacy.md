# 数据与隐私

本文对应当前 Windows x64 源码, 更新于 2026-10-29. Emily 是非官方本地归档工具, 项目不提供云端归档账户或归档托管服务.

## 本地保存什么

| 数据 | 用途与位置 |
| --- | --- |
| 归档数据库 | 当前数据根中的 `history.sqlite`, 包含账号资料、内容与来源关系、观看记录及任务状态等 |
| 可迁移设置 | 数据根中的 `settings.json`, 保存主题、同步偏好、备份策略等设置 |
| 登录资料 | 数据根中的 `profiles/`, 为账号和浏览器维护隔离的登录环境 |
| 封面与运行状态 | 数据根中的 `covers/`, `tmp/`, `diagnostics/`, `logs/` 等受管目录 |
| 目录与设备配置 | 应用配置目录中的 `bootstrap.json` 和 `device-settings.json`, 记录数据根位置及设备选项 |
| 下载与导出 | 按应用中的目录设置保存; 用户选择的外部目录可能在数据根之外 |

默认应用配置目录为 `%APPDATA%\lifearchive.douyin-history-archive`, 默认数据根是其 `Data` 子目录. 实际数据根以应用设置显示的目录为准; WebView2 和进程协调状态还可能位于本机 LocalAppData 中.

使用应用内的迁移功能更改数据目录. 迁移后可能保留旧数据根供确认和清理, 不要在应用运行时手动移动数据库或删除 WAL/SHM 文件.

## 登录与浏览器

登录在系统 Microsoft Edge 或 Google Chrome 中完成. Emily 使用应用专用的隔离 profile, 不复用日常浏览器 profile. 账号切换和浏览器选择均由应用管理.

隔离 profile 可能包含 Cookie、登录令牌及其他浏览器状态. 它是敏感的本地资料, 不能因文件保存在本机就视为可公开分享. 不要将 `profiles/` 加入代码仓库、同步给他人或作为问题附件上传.

## 哪些操作需要联网

- 登录和同步会访问抖音网页及相关服务, 内容可见性由平台和当前账号决定.
- 下载访问对应媒体地址; 开启封面缓存时会获取封面资源.
- 配置并使用更新功能后, 应用会访问构建指定的 HTTPS 更新服务并下载更新包. 自动检查和自动下载受设置控制; 缺少更新地址或公钥时功能不可用.
- 安装器在缺少 WebView2 时可能通过其引导安装器下载运行时. Edge、Chrome 和 WebView2 作为系统组件, 各自可能有独立的网络行为与隐私设置.

本地查看已经归档的记录不需要重新采集. 本地归档不表示整个应用从不联网, 也不保证远端媒体链接以后始终有效.

## 备份包含什么

应用导出的 `.emily-backup` 是**未加密备份**. 它包含数据库快照和可迁移设置, 并带有格式与完整性信息. 完整性校验不提供保密性.

备份不包含浏览器登录 profile、封面缓存、日志、诊断、下载媒体或设备专属配置. 恢复后通常需要重新登录, 并重新确认本机目录和桌面选项.

即使不含 Cookie, 数据库仍可能暴露账号资料、观看习惯、内容链接、收藏及任务信息. 请把备份保存在自己控制的存储中. 需要传输或异地保存时, 使用可信的加密存储或加密容器; 不要把原始备份附在公开反馈中.

备份恢复提供替换或去重合并方式. 操作前确认目标与备份内容; 应用生成的恢复前安全备份也应作为敏感资料保管.

## 下载、删除与卸载

删除本地归档记录不等于删除抖音上的观看历史、喜欢或收藏. 同样, 数据库中的记录也不等于已经下载了对应媒体.

下载文件、手动导出的备份和旧数据根可能位于当前数据根之外. 清理当前数据库或卸载应用时, 不要假设这些外部文件已经一并删除; 应分别检查自己选择的导出、下载和备份目录.

## 公开反馈前

反馈中保留复现步骤、应用版本、Windows/浏览器版本和错误代码即可. 分享截图或诊断前检查:

- 账号昵称、头像、UID, 以及本机用户名和绝对路径.
- 页面中的观看记录、收藏、内容标题和链接.
- Cookie、令牌、请求头、登录二维码、验证码及其他身份验证信息.
- 数据库、备份和整个浏览器 profile 的附件.

不要公开上传真实账号的数据库、备份或 profile. 若无法确定如何脱敏, 先用文字描述问题, 不附原始数据.
